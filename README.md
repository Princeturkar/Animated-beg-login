📖 Project Description

This project demonstrates how to embed a Visme Form into a web page using HTML.
Visme Forms provide a simple way to create animated and interactive forms without writing backend code.
The form includes built-in animations such as fade-in or slide effects, handled automatically by Visme’s JavaScript.

🚀 Features

Embedded Visme form

Built-in entrance animations

No backend or database required

Responsive design

Easy integration using HTML

🛠 Technologies Used

HTML5

CSS3

Visme Form Embed (Third-party service)

⚙️ How It Works

The Visme form is created on the Visme platform.

Visme provides an embed code containing a <div> and a JavaScript file.

The JavaScript loads the form dynamically and applies animations.

All form submissions are handled by Visme.
